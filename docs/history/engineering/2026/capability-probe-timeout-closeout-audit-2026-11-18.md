## 实现决策与本地验证

仅精确的能力验证 POST 采用合法后端预算（1–120 秒，默认 30 秒）加 3 秒的
BFF 截止，浏览器仍按预算加 5 秒；三套 Nginx 源配置为该路径设 130 秒。
普通 Admin 请求维持原上限。截止持续到响应体读取结束，并保留取消、授权和
幂等转发。超时返回有界 504 错误码，传输失败显示“结果尚未确认”，引导先读
证据，再决定是否承担费用重试。没有自动重试。

选择该修复是因为后端工作可以在代理返回失败后继续完成；全局延长普通请求、
自动重复探测或把传输失败直接归因于配置，都不能解决这个语义问题。

2026-11-17 的实现验证：

- 前端 Vitest 86 文件 / 1196 项通过，最终定向代理测试 20/20。
- `check:admin-ui`、TypeScript、相关 ESLint、BFF 路由契约通过。
- 原运行配置 PC 浏览器 32 项通过；新增场景修正 mock 标准信封后 2/2。
- 1440 / 900 PC 截图复核错误、未知结果、下一步均可见，草稿保留、无自动重试。
- 三套完整 Nginx 配置均通过 `nginx -t`；构建重试成功，diff 检查通过。

本轮只有文档修改，不重复运行上述功能测试；执行文档路由给出的检查及新增
相对链接存在性检查。上述本地结果不等于 GitHub CI 或人工视觉验收。
