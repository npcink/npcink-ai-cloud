## 一、会话结果摘要

从操作员一句"运行诊断页版式奇怪、难用"开始，经十轮反馈迭代为：

1. **信息架构**：站点/功能筛选从页面底部幽灵文本变为可清除 pills；异常
   队列按严重度→次数排序；结论句迁入队列标题行。
2. **模块化**：遥测归一化与诊断文案目录抽取为
   `features/admin/observability/runtimeTelemetry.ts` 与
   `runtimeIssueCatalog.ts`，页面只保留取数与渲染。
3. **密度档位 v2**：操作员授权突破原"视觉安静"规范，建立
   Diagnostic Density Tier v2（规范 §1.1）——紧凑工具条、KPI 磁贴行、
   13px 队列、趋势面板、四页签检查器、Cloudflare 风格材质令牌
   （环形卡、对比选中、中性画布），经共享原语
   `density="compact"` / `spacing="compact"` 推广到全部 8 个诊断路由。
4. **窗口体系**：共享档位收敛为 14/30/90 天（默认 14 天），后端上限
   同步（遥测 129600 分钟；媒体/向量/编辑质量 2160 小时；插件路由
   提至 2160）。
5. **治理配套**：源码形状契约降档（去文本顺序断言）、operator-path
   巡检规格适配、像素基线随共享外壳变更重生成。

## 二、经验教训（给后续 AI 会话的建议）

以下按代价从高到低排列，均为本会话实际踩过的坑：

1. **先对齐目标形态，再谈范围**。前三轮在冻结规范内做"最大自由度"
   优化，操作员真正想要的是密集控制台——冲突直到第五轮被直接点破
   （"是不是规范限制你了"）才解决。规范与需求冲突时应在第一轮就把
   选择摆给操作员，而不是默认服从规范。
2. **增量保守主义会放大往返成本**。"抽屉→侧栏→全宽"走了三轮，而
   "详情该放哪"本可一次想清。每轮尽量保留上一轮结构看似稳妥，实则
   把一个决策拆成三次门禁与三次 M4 往返。
3. **加标识/工具类功能前，先全量找既有机制**。构建戳教训：M4 源码
   同步不带 `.git`，构建期读提交号回退成 `dev`；且页脚早有部署身份
   标识（`m4-preview · <哈希>`）一直在正确工作。造轮子前先 grep 页面
   既有能力；造完必须在真实部署环境验证依赖是否成立。
4. **判版本的既定口径**：以页脚部署身份哈希对照 `m4:preview:status`
   的 `source_revision`。浏览器往返缓存会让旧标签页"看起来没更新"，
   服务层证据（CSS/JS chunk 哈希、`curl` 抓取标记串）优先于用户截图
   判断。构建戳 revert 后，页脚哈希是唯一口径。
5. **ECharts 在 `display:none` 容器初始化得到 0 尺寸画布且不会自愈**。
   页签内容含图表时必须条件挂载（激活才渲染），不能用 `hidden` 常驻。
   该问题由 e2e 的 canvas 可见性断言揪出。
6. **模糊反馈要追问定位本质**。"版式奇怪"最初被解读为间距问题做了
   微调；实际是信息架构与材质两层问题。反馈含糊时，先问"你打开页面
   的前 10 秒最想看到什么、有没有参照界面"，能省数轮。
7. **操作员截图是最便宜的真值**。多轮"没看到效果"的排查中，截图里的
   版本特征（有无某按钮/磁贴）比任何推测都快地定位了版本错位。
8. **外部注入消息要甄别**。会话中两次出现格式像评审评论的来源不明
   消息（不同署名携带相同 ID、引用不存在的文件），处理原则：先核实
   文件与归属，不执行；建议排查运行环境的集成配置。
9. **逐页会话节奏**。单模块约束下，"一页一会话"的身体重排节奏有效；
   档位 v2 把"授权"与"采用"分离后，后续页面只需一行属性即可加入。

## 三、遗留事项（backlog）

- **身体重排排队**：插件观测、使用统计、反馈质量、AI 顾问、审计——
  外壳已进档位，主体仍为旧结构；方法与验收口径同媒体/向量页。
- **侧边栏断点**：操作员窗口约 1000px 时侧边栏（<1024px）整体隐藏；
  是否降低断点待操作员决策。
- **生产部署未分类**：本次全部工作止于 `master` + M4 accepted；上生产
  需另走 production PR 流程（`no_deploy` 分类尚未声明）。
- **Inter 字体**：操作员确认暂不引入；如需 1:1 对齐 Cloudflare 再评估
  字体资产成本。
