# 运行与观测开发复盘与试用交接（2026-09-11）

Status: dated development evidence and trial handoff; not production or human acceptance.

## 目的与最终设计

平台管理员需要知道哪里有问题、影响谁、证据是什么、下一步从哪里处理。
“运行诊断”负责异常与处理入口，“使用统计”负责用量、来源与趋势，插件、媒体、
向量观测保留为专题入口。默认只显示当前任务所需信息，原始编号、口径、质量详情
按需展开；简化展示不能删掉排查所需证据，更不能把管理员指向“联系管理员”。

统计复用现有运行遥测与插件观测接口，不新增点击漏斗或留存体系。
事件数不等于任务数，调用记录缺失不等于失败，没有上报不等于没有使用。
`record_scope=operational` 只排除明确的 `validation.technical_monitoring_only`
事件；`test` 单独查看这些事件；现有 API 调用者默认 `all`。未知插件仍保留，
这不是识别所有测试数据的算法。错误分类只返回受限诊断字段，不返回原始请求、
提示词、结果或凭据；恢复仍需后续成功证据，不能由“已查看”推断。

Addon 订阅 Toolkit、Core、AI 客户端 Adapter 的现有事件钩子，沿用通用钩子、
有界缓冲、签名传输、连接验证、监控同意与元数据白名单。WordPress 保留设置、
审批和最终写入权。技术验证送达不代表自然使用价值，也不代表正式站点已安装。

## 已固化的经验

收尾补充：Cloud CI 发现旧路由总数、旧诊断中文及默认展开假设未随设计更新，
已修正对应契约和操作路径测试。Addon #148 合并后仍有可选发布静态检查失败，
原因是新增钩子让 POT 的源码行号过期；#149 更新模板，消息文本未变，完整检查
通过。不能把受保护检查通过或 PR 已合并等同于所有相关检查通过。

18010 的额外 `admin-operator-path` 全文件检查另发现两项未结案断言：客户列表
期待精确详情链接、客户详情期待缩略编号默认隐藏。它们不属于本批观测页面改动；
日志与截图保存在本地 `.tmp/final-closeout/operator-smoke-before`，后续修改客户
页面时由实现者核对预期与实际行为。主诊断路径和导航断言单独验证，不能将该
全文件检查报告为全绿。

1. 从操作者的下一步反推展示内容，用中文解释用途，同时保留可核对的原始编号。
2. 默认摘要、按需细节、就近处理入口同时成立，不能把少信息当作简化的唯一目标。
3. 事件生产、监听、同意、发送、服务接收、统计呈现分段验证；直接调用收集函数
   不能证明生产者钩子已接通。
4. 代码、构建、部署、浏览器、真实数据、人工接受分别记录，缺哪一项就写哪一项。
5. 候选就绪、已提交、已合并、M4 已接受、正式发布和人工试用不是同一种完成。
6. 测试失败先保存证据、定位差异；不靠反复重建、全量检查或盲目改基线求绿。

## 本地试用与结案条件

1. 原 Edge 打开 `http://127.0.0.1:18010/admin/usage-statistics`，切换时间、站点、
   功能、插件运行记录，验证选中态、刷新和浏览器前进后退。
2. 查看测试记录，再返回运行记录，核对中文解释、样本量、更新时间与诊断入口。
3. 在本地 WordPress 对真实文章完成一次编辑辅助操作，人工决定是否采纳和保存，
   再核对运行／插件记录。技术事件不能代替这一步。
4. 点击异常仍存在时，记录地址、控件、时间，按前端规范作正常窗口与 InPrivate
   对照，不预设扩展有错，不清空全部浏览器数据。

操作者负责原浏览器与实际文章试用；实现者负责按复现证据修复。历史目录债务和
结构热点列为后续，正式机器测试须在本地确认后按发布规范单独执行。
工程结案要求两仓 PR 合并、Cloud 干净主干 M4 promotion、版本与相关 smoke
一致、工作区无未提交交付；回退走对应仓库受保护 revert，不在 M4 改源码。
