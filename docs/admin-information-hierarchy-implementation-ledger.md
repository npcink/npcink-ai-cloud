### 本批已确认的取舍与迁移入口

- 用量来源与当前范围不折叠；刷新、表图切换、统计维度在同一工具条。
  保留默认表格、插件分页/快照、跨页诊断参数及截断警告。
- 质量页常显样本阶段、分子/分母、待定数及不足限制；删除重复「质量证据详情」
  标题。导出和固定只读边界进入「证据边界与导出」，任务筛选/刷新常显。
  真实趋势保持展开；有会话但没有区间数据时写「未返回区间趋势证据」，
  不显示「没有会话」，空趋势不保留大块图表占位。
- 反馈的问题标签队列放在推荐保存表之前。没有标签时保留样本数和结论限制，
  不渲染大块「无问题」卡。场景表进入「运行时与界面质量」，完整 runtime/surface
  在该表可读；标签/来源/小时桶进入同名披露区。已有 URL focus、请求和统计不变。
- 审计常用筛选先行；事件 ID、幂等键、scope 和精确时间等仍在「更多筛选」。
  折叠区外显示所有已生效条件；十一字段提交、时间精度、失败/未知结果、
  分页和 Inspect 保留。只降低成功心跳/cadence 的视觉强调，不过滤、重排或少采集。
- 排障的上下文下一步和底部工具入口用途不同；保留直接、低强调导航。
  媒体空态的启用式指导已在 #1312 修复；原报告是旧基线，不重新引入或重写。
