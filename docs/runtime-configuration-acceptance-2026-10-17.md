## 已确认的原因与修复边界

1. 页面原先在保存任意配置时验证全部已选媒体候选，再完整替换六组配置。
   一个历史图片验证失败会阻断文字配置。本候选增加同权限、同幂等保护的
   `PATCH /internal/service/admin/runtime-profiles`，仅校验和保存提交的组。
   前端仅提交有改动的组，未改组不探测、不改写 revision。完整 `PUT` 合同保留。
   修改媒体候选仍需当前有效能力证据；不是放开未验证模型。
2. 列表原先只看连接健康，弹窗读取能力证据。本候选让配置与候选使用同一
   健康/能力判断，并检查候选链。连接目录可读不等于对应生成接口可用。
3. 预算选项来自已有连接，展示名称和实际 runtime Provider ID。
   `mqzj` 连接的预算键是 `openai`；同键连接共享计数，只显示一个选项。
   旧的、已无连接的预算行保留并标注，避免静默丢失配置。
   本轮只修正管理投影，不改派发、额度预留、计量、幂等或回调事务。
4. Addon 独立候选补官方 AI 插件安装/启用指引，以及知识库读取失败的状态说明。
   不自动安装、不运行测试，不修改内容投递、历史恢复或索引生命周期。
