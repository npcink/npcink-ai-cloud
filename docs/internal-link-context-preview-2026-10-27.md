| 证据状态 | 候选数 | 含义 |
| --- | ---: | --- |
| 指定来源段落中有唯一字面锚点 | 88 | 可定位文字，非插入安全或语义通过 |
| 指定来源段落中锚点重复 | 24 | 保留歧义，不选定某次出现 |
| 没有锚点 | 7 | 保留候选，不制造后备锚点 |

| 正文可提取字面锚点窗口 | 82 | 最多两个窗口；另保留原检索 chunk，不称为语义支持段落 |
| 来源有字面公开 URL token | 17 | 只是文字证据，不解析或抓取链接 |

这将“缺少证据”和“推荐错误”分开记录。没有在清洗正文里找到 URL，并不证明原文
没有资源链接；后续应核对已有公开引用采集/清洗链能提供什么，不能仅凭相似名称
断言同一资源，也不能凭不同文章 ID 或名称差异断言不同资源。

## 固定 12 题的 AI 对照

复用上一轮已观察的 12 个开发诊断题。保持模型、顺序、批次、候选、锚点、原有
证据和 v5 rubric 不变；新输入只增加 `review_evidence.context_preview`。
移除该新增字段后两个输入逐项一致。每模型、每条件 3 批，每批 4 项；四组均完整
通过原 Eval Lab v5 校验。模型是 `qwen3.8-max` 和 `deepseek-v4.1-flash`。

| AI 意见分布（12 项） | 原输入 | 增加上下文投影 |
| --- | --- | --- |
| Qwen：fits / misleading / unknown | 4 / 8 / 0 | 4 / 7 / 1 |
| Qwen：ready / not_eligible / manual_only | 4 / 7 / 1 | 3 / 7 / 2 |
| DeepSeek：fits / misleading / unknown | 10 / 2 / 0 | 7 / 5 / 0 |
| DeepSeek：ready / not_eligible / manual_only | 7 / 2 / 3 | 6 / 5 / 1 |
| 两模型目的地意见不同 / 插入意见不同 | 6 / 6 | 3 / 3 |

三个有支持的开发正例 `19025→20974`、`22055→3487`、`18817→276125`
在两个条件、两个模型中均保持 ready；两个明确任务错配 `11926→15356`、
`22055→9128` 均保持 misleading。`9358→10554` 从两模型 fits/ready 变为
misleading/not_eligible：当前主题对某插件的兼容性不能由另一款主题介绍来解释。
这是值得继续验证的个案，不是整个产品的准确率提升。

剩余问题仍明显：DeepSeek 对 `21807→556` 仍把原图床的上传功能链接到另一图库
产品；`16666→16663` 的模型意见仍分歧；`278400→279803` 虽变得更保守，现有
证据仍不足以确认资源身份；`7955→5386` 对“提及术语是否足够解释”的判断仍有
分歧。模型一致不是 ground truth，保守判错也不自动等于正确。

这是已看开发题的单次对照，没有新独立留验或重复采样，不能排除模型波动，也不能
把分歧减少当正确率。未形成可上线的阈值、AI 自动过滤政策或生产延迟/成本结论。
具体语义改进和实际 API/Addon/编辑器验收仍未完成。

  TLS 验证后另存新轮次，未修改仓库配置、未覆盖旧失败。
- 独立 Qwen 代码审查送达 6 条意见。F1 修复重复 body hash 计算，F3 明确 Git
  失败代码，F6 增加真实字节 SHA 的 CLI 集成测试；F2 为已有独立 ValueError
  处理的误报，F4/F5 是有界正则和非穷尽窗口的可接受取舍。完整处置保留在原始目录。
