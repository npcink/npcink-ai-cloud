Npcink Cloud Privacy Policy

This Privacy Policy explains what information Npcink Cloud may receive when a WordPress site administrator connects a site to Npcink Cloud through the Npcink Cloud Addon plugin.

Information We Receive

WordPress AI and runtime: when a local feature explicitly runs, the request can include the prompt or source text and task configuration needed for that result.

Media: when a bounded media job is explicitly started, the request can include selected image/media bytes or a short-lived source artifact descriptor and derivative parameters.

Site Knowledge: when delivery is enabled, public posts/pages and public metadata may be sent for Cloud-owned indexing. Drafts, private or password-protected content, credentials, and raw database fields are excluded.

Monitoring: only optional metadata such as plugin version, event kind, status, timing, error code, route, identifiers, counters, and latency. Monitoring does not include prompts, article content, generated content, or media bytes.

Information We Do Not Intentionally Collect

The Cloud API Key secret is used for server-side signing by the local WordPress site and is not printed in wp-admin. The configured Cloud service controls retention and deletion under its data retention policy.

Optional Monitoring

Plugin monitoring is optional and requires explicit administrator opt-in. When enabled, monitoring may upload operational metadata such as plugin slug, plugin version, event kind, status, timing, error code, route, proposal id, ability id, correlation id, counters, and latency.

For supported editor journeys, this may record that generation started, succeeded, failed, was retried or accepted, and whether an accepted result was saved or abandoned. It does not send prompt text, source or generated content, raw WordPress user or post IDs, email addresses, URLs, DOM data, credentials, or free-form error messages.

Uploads are authenticated to the configured Cloud site and may therefore be associated with that site. Monitoring data is used to diagnose failures, measure reliability, and improve Npcink features. It is not used for advertising, individual user scoring, automatic approval, or automatic WordPress content changes. Monitoring is off by default and an administrator can turn it off at any time.

How We Use Information

Npcink Cloud may use received information to authenticate and verify signed requests, provide hosted runtime features, return health, entitlement, and usage summaries, process bounded media derivative jobs, provide optional observability and quality summaries, protect service reliability, prevent abuse, and troubleshoot service errors.

Data Sharing

We do not sell personal information. We may share limited data with infrastructure providers, security providers, or service processors only as needed to operate Npcink Cloud.

Data Retention

Operational logs, request metadata, entitlement records, and monitoring summaries are retained only as long as needed for service operation, security, debugging, abuse prevention, accounting, or legal requirements.

Deletion Requests

Site administrators may request deletion of account-linked service data by contacting: npc@npc.ink.
