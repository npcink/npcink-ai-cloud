Npcink Cloud 隐私政策

本隐私政策说明，当 WordPress 站点管理员通过 Npcink Cloud Addon 插件将站点连接到 Npcink Cloud 时，Npcink Cloud 可能接收哪些信息。

联系邮箱：npc@npc.ink
服务域名：https://cloud.npc.ink

我们接收的信息

服务元数据：常规连接和只读请求可能包含已配置的站点与密钥标识、请求时间戳、nonce、trace 与幂等标识、HMAC 签名请求头、Cloud Base URL 目标、健康检查、运行状态或结果读取，以及用量、权益或可观测性摘要请求。

WordPress AI 和 runtime：本地功能明确运行时，请求可能包含用于生成结果的 prompt 或 source text、任务配置以及必要的技术标识。

Media：明确启动受限媒体任务时，请求可能包含选定的图片/媒体字节，或短期 source artifact descriptor 和 derivative parameters。

Site Knowledge：启用投递后，公开文章/页面及其公开元数据可能发送给 Cloud 进行索引。草稿、私密或受密码保护内容、凭据和原始数据库字段不会发送。

Monitoring：仅发送插件版本、事件类型、状态、耗时、错误代码、路由、标识符、计数和延迟等元数据，不包含 prompt、文章正文、生成内容或媒体字节。

我们不会有意收集的信息

Cloud API Key secret 仅由本地 WordPress 站点用于服务端签名，不会打印到 wp-admin 页面。数据保留和删除由已配置的 Cloud 服务依据其数据保留政策负责。

可选监控

插件监控是可选功能，需要管理员明确同意。启用后，可能上传插件标识与版本、事件类型、状态、耗时、错误码、路由、业务关联标识、计数和延迟等运行元数据。

对受支持的编辑器使用流程，可能记录生成已开始、成功、失败、重试、接受，以及接受后是否保存或放弃。不会发送 Prompt 文本、源内容或生成内容、WordPress 用户或文章原始 ID、邮箱、URL、DOM 数据、凭据或自由文本错误消息。

上传请求会使用已配置 Cloud 站点的身份认证，因此这些数据可与该站点关联。监控数据仅用于排查故障、衡量可靠性和改进 Npcink 功能，不用于广告、个人用户评分、自动审批或自动修改 WordPress 内容。该功能默认关闭，管理员可随时关闭。

信息用途

Npcink Cloud 可能使用收到的信息来认证和验证签名请求、提供 hosted runtime 功能、返回 health、entitlement 和 usage summaries、处理 bounded media derivative jobs、提供可选 observability 和 quality summaries、保护服务可靠性、防止滥用并排查服务错误。

数据共享

我们不会出售个人信息。我们可能仅在运营 Npcink Cloud 所需范围内，与基础设施提供商、安全提供商或服务处理商共享有限数据。

数据保留

Operational logs、request metadata、entitlement records 和 monitoring summaries 仅在服务运营、安全、调试、滥用防范、会计或法律要求所需期间保留。

删除请求

站点管理员可以通过 npc@npc.ink 请求删除与账户相关的服务数据。
